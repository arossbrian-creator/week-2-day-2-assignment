# Week 2 Day 2 Assignment: JavaScript Functions

## What's in this project

- **`calculateTip(billAmount, numberOfPeople, serviceQuality)`** works out the tip and each person's share of a bill. The tip rate is 10% for poor service, 15% for good, and 20% for excellent. It returns an error message if the number of people is 0 or less, or if the bill is negative.
- **`calculateGrade()`** is meant to calculate a weighted average, letter grade and pass/fail status from a list of assessments. It is not finished.
